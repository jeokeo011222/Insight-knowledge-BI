fix: 后端支持 SQLite 元数据库（无需 Docker / PostgreSQL 也能跑）

database.go: Connect() 根据 DSN 前缀选 driver
- sqlite:// / sqlite: → gorm.io/driver/sqlite (纯 Go, 无需 CGO)
- 其他 → gorm.io/driver/postgres (原行为)

go get gorm.io/driver/sqlite

零依赖启动方式:
  SQLALCHEMY_DATABASE_URI=sqlite://data/superset.db
  REDIS_URL=
  go run ./cmd/superset init
  go run ./cmd/superset run --port 8088

这样可以在没有 Docker Desktop 的机器上直接跑起来。
